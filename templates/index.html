Formulas Used

1. Prandtl-Meyer Function

ν(M) = √[(γ+1)/(γ−1)] tan⁻¹√[ ((γ−1)/(γ+1))(M²−1)] − tan⁻¹√(M²−1)

2. Maximum Prandtl-Meyer Angle

νmax = 90°[√((γ+1)/(γ−1)) − 1]

3. Mach Angle

μ = sin⁻¹(1/M)

4. Expansion Relation

θ = ν₂ − ν₁

5. Downstream Prandtl-Meyer Angle

ν₂ = ν₁ + θ

6. Temperature Ratio

T/T₀ = 1 / [1 + ((γ−1)/2)M²]

7. Pressure Ratio

p/p₀ = [1 + ((γ−1)/2)M²] −γ/(γ−1)

8. Density Ratio

ρ/ρ₀ = [1 + ((γ−1)/2)M²] −1/(γ−1)

9. Critical Mach Number

M* = √[(γ+1)M² / (2 + (γ−1)M²)]

10. Area Ratio

A/A* = (1/M) [ (2/(γ+1)) (1 + ((γ−1)/2)M²) ] (γ+1)/(2(γ−1))

11. Downstream Mach Number

ν(M₂) = ν₁ + θ

M₂ is obtained numerically using the bisection method.

12. Temperature Ratio Across Expansion

T₂/T₁ = (T₂/T₀) / (T₁/T₀)

13. Pressure Ratio Across Expansion

p₂/p₁ = (p₂/p₀) / (p₁/p₀)

14. Density Ratio Across Expansion

ρ₂/ρ₁ = (ρ₂/ρ₀) / (ρ₁/ρ₀)
